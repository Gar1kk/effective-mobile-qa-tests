# Тестовое задание Effective Mobile — QA

Проект для КТ2 по дисциплине «Основы IT-технологий».

**Роль:** тестировщик (QA).

**Компания:** Effective Mobile.

**Исходное задание:** https://github.com/Hexlet/ru-test-assignments/blob/main/qa/effective-mobile/README.md

## Что делаю

1. UI-тест на Python и Selenium: авторизация на сайте SauceDemo, добавление товара в корзину, оформление заказа и проверка успешной покупки.
2. API-тест на Python: создание публичного тестового репозитория через GitHub API, проверка его наличия и удаление.

## Что не делаю

Не выполняю дополнительные сценарии покупок, нагрузочное тестирование и проверку других пользователей. Эти проверки не входят в основные требования выбранного задания.

## Запуск и проверка

Инструкции по установке зависимостей, запуску тестов и проверке результатов будут добавлены после реализации.
